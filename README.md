Описание:
В данном репозитории представлены решения пяти задач на языке Python, выполненных в рамках лабораторной работы №3. 
Работа посвящена основам объектно-ориентированного программирования, созданию классов, использованию итераторов и модульному тестированию.

Структура проекта:
lab3_simple_num2.py — простая задача №2
lab3_simple_num8.py — простая задача №8
lab3_simple_num10.py — простая задача №10
lab3_normal_num3.py — задача средней сложности №3
lab3_normal_num10_counter.py — задача средней сложности №10
test_counter.py — unit-тесты для класса Counter
.gitignore — исключение служебных файлов из Git

Запуск программ:
Для запуска необходимо установить Python 3.

Склонировать репозиторий:
git clone https://github.com/Anastasy-prog/lab_3.git

Перейти в папку проекта:
cd lab_3

Запустить нужную программу, например:
python lab3_simple_num2.py

Для запуска unit-тестов выполнить:
python -m unittest test_counter.py

При успешном прохождении тестов выводится сообщение OK.
